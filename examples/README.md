# AutoMetaRAG Examples

This directory contains example scripts demonstrating how to use AutoMetaRAG.

## Files

- **test1.py**: Example of querying an existing indexed collection
- **test2.py**: Example of the complete ingestion pipeline (schema generation + indexing)

## Usage

These examples assume you have:
1. Set up your `.env` file with API keys
2. Created a `config.ini` file for metadata configuration
3. (For test2.py) Have sample data in the expected location

Note: The paths in these examples are relative to the AutoMetaRAG directory. Adjust them according to your project structure.
